# Boxes.py joint library

`search_joint_templates(query, limit=5)` searches actual installed generator source, descriptions, declared joint settings and literal wall edge sequences. Results include parameter schemas and a SHA-256 source fingerprint. Scan failures remain visible. The index is cached in each server process and rebuilt from the installed source after deployment; it does not depend on temporary storage.

Assembly plans include three source references. Explicit requests for a Boxes.py template without a photograph route to its generator. Supplied vectors and custom silhouettes retain precedence: a generic matching holder is not an exact house-shaped holder.

This implements retrieval and code reuse, not neural training or autonomous verification. Rendering a template is not evidence of paired custom slots or physical fit. Source expressions and dynamic edge selection are not fully resolved by the literal-sequence scan; read the generator code/schema when necessary.

Further learning needs a durable, scoped registry of successful recipes and human measurements (actual thickness, kerf, joint play, assembly result). Failed or merely imported files must not enter that registry as verified examples. Artifact deletion after 24 hours should not erase approved reusable recipes; that distinction requires a separate retention policy before adding the registry.
