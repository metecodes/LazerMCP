ChatGPT

Plus, Pro, Business, Enterprise veya Education. Web. OpenAI Developer mode belgesi, 2026.

Bireysel — Google

  1. chatgpt.com aç.
  2. Settings → Security and login → Developer mode açık.
  3. Plugins (Apps) git. + bas.
  4. Ad: LaserMCP. URL: https://mcp.metehanavci.com/mcp
  5. Kimlik: OAuth. Google penceresinde bu hesaba gir.
  6. Sohbette + → Developer mode → LaserMCP’yi aç.

Kurumsal — API anahtarı

  1. /account sayfasında Google ile gir. İzinli kurumsal e-posta ise anahtar üret.
  2. ChatGPT web yine OAuth ister; her kişi kendi Google’ı ile bağlanır.
  3. Otomasyon ve Cursor: Authorization: Bearer lzr_…
  4. Canlı sitede yalnız Authorization başlığı. URL’ye token koyma.

Claude

claude.ai, Cowork, Desktop. Anthropic Help Center, Ağustos 2026. Free planda 1 özel bağlayıcı.

Pro / Max — Google

  1. Customize → Connectors.
  2. + → Add custom connector.
  3. URL: https://mcp.metehanavci.com/mcp
  4. Add. Connect. Google ile bu hesaba gir.
  5. Sohbette + → Connectors → LaserMCP açık.

Team / Enterprise

  1. Owner: Organization settings → Connectors → Add → Custom → Web.
  2. Aynı MCP adresini yapıştır. Add.
  3. Üye: Customize → Connectors → Connect → Google.
  4. Atölye otomasyonu için kurumsal API anahtarı kullan; çıplak link değil.

Cursor

Yerel MCP. Bireysel OAuth; kurumsal Bearer anahtar.

  1. Cursor Settings → MCP → Add new global MCP server.
  2. Type: streamableHttp. URL: https://mcp.metehanavci.com/mcp
  3. Bireysel: bağlarken Google.
  4. Kurumsal headers: Authorization: Bearer lzr_…
