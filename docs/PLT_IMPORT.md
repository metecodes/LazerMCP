# PLT import and completeness checks

Use create_design(plt="IN;SP1;PU0,0;PD400,0,400,400,0,400,0,0;PU;", parameters={"format":"both"}) or plt_base64 for ASCII HP-GL file contents. Exactly one of svg, plt, plt_base64, preset or primitives is accepted. The existing POST /api/cad/design accepts the same JSON fields. The editor provides PLT içe aktar and opens a new project without modifying the current one; save an existing dirty draft first.

HP plotter units default to 40 per millimetre (0.025 mm each), per the HP PCL/HP-GL reference: https://www.hp.com/ctg/Manual/bpl13211.pdf. Set parameters.plt_units_per_mm explicitly for a different exporter. Linear SC scaling requires explicit IP bounds so dimensions are not guessed. Source coordinates are measured in millimetres, normalized with a 2 mm margin and converted from Y-up to SVG Y-down once. Translation and orientation are baked into path coordinates to survive operation grouping.

Supported: IN, DF, SP, PU, PD, PA, PR, AA, AR, CI, EA, ER, IP, linear anisotropic SC, RO 0/90/180/270 and a terminal PG. Common LT/VS/PW/PC/LA/WU presentation instructions preserve the underlying vectors and are listed as ignored styling in plt_import.warnings. Curves are tessellated with maximum 0.02 mm chord error. Pen 0 produces no geometry. Pen changes and pen-up movements never connect unrelated paths.

Defaults assign vectors to CUT. parameters.plt_default_operation and parameters.plt_pen_operations={"2":"ENGRAVE"} explicitly control operations. Import metadata records units, original bounds, path counts, pen mapping and ignored styles. The normal geometry/manufacturing Final Gate still runs and SVG/DXF artifacts retain the 24 hour policy. Open CUT paths remain open and may be BLOCKED; the importer never invents a closing edge to satisfy the gate. A PLT cutting sheet supplies 2D paths and does not provide 3D placements or mechanical partner data.

Limits: 5 MB ASCII input, 100000 instructions, 200000 points, 10000 segments per curve. Binary PLT/DMPL, text labels LB, compressed PE, polygons PM/FP/EP, Bezier BZ/BR, wedge WG/EW, implicit/device-dependent scaling and multi-page drawings fail explicitly. Unsupported commands never result in an apparently complete saved drawing.

Completeness: quoted model/part names alone no longer imply lettering. Negative clauses such as pervane yok / yazı yok / no rotor do not require absent features. Actual requested lettering still requires text markings; an engraved icon cannot stand in for lettering. Only roof panels trigger the separate-gable completeness rule, not house-shaped contour labels or roof braces. Failed checks remain critical. BLOCKED cards now include BLOCKING REASONS and structured blocking_checks, and create_design preserves look_again from the internal pipeline. The original blocked file was not supplied, so these are reproduced checker defects, not a confirmed diagnosis of that particular job.

Validation: focused Python regressions exercise false positives and actual missing parts, original-unit dimensions, PU/PD and PA/PR state, circles/arcs, scaling/rotation, pen operations, wrappers, unsupported commands, malformed/binary/multi-page input, SVG orientation after manufacturing grouping and MCP base64 generation. Browser tests exercise upload, preview/download and preserving the existing drawing after a rejected upload.
